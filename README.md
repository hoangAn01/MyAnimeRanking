## Chạy / Deploy
- Local: `cp .env.example .env`, điền `MONGODB_URI`, rồi `npm install && npm start` → http://localhost:3000
- Render / Vercel: đặt biến môi trường `MONGODB_URI` trong dashboard (không commit `.env`). MongoDB Atlas cần cho phép IP `0.0.0.0/0`.
- GitHub Pages chỉ phục vụ thư mục `public/` và gọi API trên Render.
